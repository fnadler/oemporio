Design System

A identidade do O Empório traduzida em tokens e componentes para o site institucional e o CRM/Manager. Construído a partir do Guia de Marca REV_007 (aprovado): monocromático charcoal, acabamento de papel quente e acentos terrosos.

Ericeira, Portugal Craft Beer Comfort Food Light + Dark PT / EN
Esta é a versão fiel ao guia aprovado: cor de marca charcoal #221E1F, neutros cinza e paleta de apoio coral / tijolo / pêssego / mauve. Tom de voz: “Beber, comer, estar entre amigos.” Use o seletor Claro/Escuro no topo.

Boas práticas
Faça
  • Use os vetores oficiais (AI/PDF).
  • Respeite a área de proteção.
  • Charcoal no claro, branco no escuro.
  • Acentos quentes só em apoio, nunca no logo.
Não faça
  • Não recolora o logo (ele é monocromático).
  • Não distorça, incline ou aplique sombras extras.
  • Não use sobre fundos de baixo contraste.
  • Não recrie o logo — sempre o arquivo real.
01 · Base

Tipografia

Três níveis, todos embutidos (offline): Bourton Drop Shadow no Display e H1 — o gesto de marca, em tamanho grande. Bourton Base Drop em todo texto curto — títulos menores (H2–H4), labels, botões, badges e navegação, sempre em caixa-alta. Work Sans apenas em textos longos — parágrafos, descrições e conteúdo de tabelas.

O EMPÓRIO

Bourton Drop Shadow · Display + H1

Empório

Bourton Base Drop · títulos curtos, labels, botões, badges, nav

Um pub acolhedor no coração da Ericeira, com cervejas artesanais locais.

Work Sans · textos longos (parágrafos, descrições, tabelas)

Regra prática: se é uma frase, é Work Sans. Se é um rótulo (1–3 palavras), é Bourton Base Drop em caixa-alta. Se é o destaque principal da tela, é Drop Shadow.
